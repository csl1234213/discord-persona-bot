# 開始使用

本包供正式 Bot 的受控試運行，由客戶自行安裝、維護及保管密鑰。
完整安全驗收尚未完成；不是安全認證或全面正式發布。

## 包內內容

- `source.zip`：可修改的程式與安全啟動設定。
- `runtime-image.tar`：本輪驗證的現成執行映像，不含模型。
- `CHECKSUMS.json`：檔案摘要及映像ID，供核對版本。
- `SBOM.json`：映像內軟體清單，供維護者檢查依賴。
- `驗收狀態.md`：實際驗證範圍與未完成項目。
- `維護更新.md`：停止、備份、更新及回滾注意事項。
- `LICENSE`：MIT授權文字；不授予任何真人文字或錄音使用權。

本包不提供 Token、模型服務密鑰、人物私人文字、音訊或聊天資料庫。
不要使用交付方的伺服器、帳號或模型服務。

## 先做準備

需要 Docker 與 Compose，Windows 使用 Docker Desktop 的 Linux 容器模式。
網絡需能正常連到 Discord。先選一個自己的伺服器與專用文字頻道，限少量使用者。

1. 建立自己的 Discord Application/Bot。
2. 開啟 Message Content Intent；不要開啟不需要的其他讀取權限。
3. 邀請 Bot，只給查看、發送、讀取歷史和嵌入連結權限，不給管理員。
4. 檢查頻道覆蓋，避免從其他角色繼承管理頻道、管理權限或Webhook權限。
5. 私下保存自己的 Token。不要傳給交付方、寫入聊天或截圖。

## 安裝啟動

解壓 `source.zip` 到新資料夾，以下 PowerShell 指令在該資料夾執行。
不要覆蓋既有 Bot 的設定或共用資料卷。固定使用本手冊的專案名，避免另啟第二份程序。

```powershell
Copy-Item config.example.env config.env
New-Item -ItemType Directory -Force .secrets | Out-Null
docker load -i '<runtime-image.tar 的完整路徑>'
```

只在本機編輯 `config.env`，填入自己的以下設定：

- `DISCORD_GUILD_ID`：伺服器ID。
- `DISCORD_CHAT_CHANNEL_ID`：專用文字頻道ID。
- `DISCORD_OWNER_USER_IDS`：建立者使用者ID；多人以逗號分隔。
- `DISCORD_ENABLE_MESSAGE_CONTENT_INTENT=true`。

以文字編輯器把 Token 保存為 `.secrets/discord_bot_token`，檔案只放Token本身，限制只有自己的帳號可讀。
不要在 `config.env` 同時填 `DISCORD_BOT_TOKEN`，不要在終端指令直接貼Token。

載入映像後，依 `CHECKSUMS.json` 的 `image_id` 逐字填入下方占位符。
這個標記只在自己的Docker內建立，不會上傳網絡。

```powershell
docker tag '<CHECKSUMS.json 的 image_id>' persona-release-audit:local
docker compose -p persona-customer -f compose.release.yml config --quiet
docker compose -p persona-customer -f compose.release.yml run --rm --no-build bot python -m scripts.seed_demo_persona
docker compose -p persona-customer -f compose.release.yml up --no-build -d
docker compose -p persona-customer -f compose.release.yml logs --tail 30 bot
```

演示初始化會寫入合成資料，並先完成資料庫更新。不要繞過啟動入口。
看到 `Bot ready discord_ready=true` 才表示該次Discord連線就緒；健康檢查正常不代表所有功能通過。

## 先試聊天

在指定頻道傳送「先把已知事实说清楚，再讨论可能的判断。」確認只收到一次回覆。
預設 `LLM_PROVIDER=fake` 是示範回答，不是真實模型，也不是已配置完成的自然對話服務。
請先以合成資料試用管理指令、TXT預覽與確認匯入，再加入有權使用的資料。

需要真實模型時自行選擇可信服務，設定模型網址、名稱、密鑰及有限額度。
發行模式必須填寫已核實的 `SECURITY_PRICE_MICROS_PER_TOKEN`；單位為每Token的百萬分之一美元。
僅確認不計費的本機服務可填0。不要為了能啟動而猜價格或取消安全模式。
真實模型品質、注入安全及故障恢復仍需客戶獨立驗收。

## 遇到問題

先停止，不要反覆重試、開放管理員權限或更換生產資料測試。
回報版本摘要、操作步驟、脫敏截圖及安全錯誤ID；不要提供Token、完整設定、附件URL或私人資料。
修正版需保留備份、先在隔離位置驗證，再安排更新。更新不保證能撤回已外洩或已刪除的資料。
